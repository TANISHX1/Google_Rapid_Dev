## 1. Core Concept & The Hackathon Pivot
*   **The Product:** AccessOps is an autonomous Multi-Agent Orchestrator designed to completely automate Accessibility (A11y), Security, and Performance code remediations.
*   **The Trigger:** When a developer opens, updates, or reopens a Merge Request (MR) in GitLab, the system intercepts the webhook, analyzes the code via Gemini 2.5 Pro, and pushes commits containing the fixed code directly back to the branch, finishing by leaving a review comment and generating compliance reports.
*   **The Pivot:** Initially pitched as a simple accessibility bot, the project was pivoted to an "Enterprise Suite" featuring an Orchestrator that spawns multiple sub-agents, combined with a highly visual "God-Mode" React dashboard that streams the agent's live thought process via structured WebSockets. It is now fully deployed as a Cloud-Native service.

## 3. Detailed Component Walkthrough

### A. The Backend & Agent Service
*   **`routes/webhook.ts`:** Implements the **Layer 1 Anti-Loop Guard** by dropping payloads generated by the `rapid-dev-agent`.
*   **`services/agentService.ts`:**
    *   **Layer 2 Anti-Loop Guard:** Validates `timeAgo` limits and strictly verifies that the latest commit does not possess the `[AccessOps]` prefix.
    *   **Structured Events:** Emits `emitAgentEvent()` via WebSockets with strict typing (`workflow:start`, `tool:call`, `tool:result`, `workflow:complete`).
    *   **Live Metrics:** Computes ROI (Tokens Saved, Time Saved) and emits them alongside `workflow:complete`.
    *   **Strict Prompts:** Enforces CRITICAL RULES in the Gemini prompt, explicitly enforcing the `[AccessOps]` commit prefix.

### B. The Custom MCP Interceptor (`backend/utils/mcpWrapper.cjs`)
A Node.js interceptor that runs the official GitLab MCP server as a child process. It intercepts `stdout` streams, searches for invalid JSON schemas lacking a `type` property, and patches them on-the-fly to prevent Zod crashes in the SDK.

### C. The Frontend (`frontend/`)
*   **Vite Proxy & Nginx:** `vite.config.ts` (local) and `nginx.conf` (production) map `/api` and `/socket.io` directly to the backend. This enforces a **Socket Singleton** pattern relative to the host, completely bypassing CORS constraints.
*   **Structured Parsing:** Uses `parseRealTimeLog` and structured React state to separate agent events from chat logs and map them to the Monaco Diff Editor.

## 5. Strict Development Rules for AI Agents

1.  **Anti-Loop Guard Rule:** Never bypass the commit prefix checks or `timeAgo` timers in `agentService.ts`.
2.  **Commit Prefix Rule:** All commits generated by the agent MUST begin with `[AccessOps]`.
3.  **Vite Proxy Rule:** Never hardcode absolute backend URLs in the frontend. Always rely on the relative `/api/` path and let Vite/Nginx proxy it.
4.  **Socket Singleton Rule:** Only instantiate `io()` once in `LandingPage.tsx` or `App.tsx` using a React `useRef` to prevent memory leaks and infinite rendering loops.
5.  **Structured Events:** Never use standard `console.log()` in the agent loop. Always use `emitAgentEvent()` to ensure UI synchronization.
6.  **MCP Interceptor:** Never attempt to use the official MCP server directly. Always route through `mcpWrapper.cjs`.
